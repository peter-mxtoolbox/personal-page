Personal Gmail MCP

Personal Gmail MCP is a private, single-user tool. It lets an AI assistant running on its owner's own computer search and read the owner's own Gmail, read-only, when the owner asks it to. It is not offered to the public and has no other users.

Privacy policy

Last updated 22 November 2026.

  • Data accessed: Gmail messages, threads, labels and attachments in the owner's own account, through the read-only gmail.readonly scope. The tool cannot send, delete or change mail.
  • How it is used: only to answer the owner's own requests in their AI assistant session. Message content the owner asks about is passed to that assistant to produce the answer.
  • Storage: the OAuth token is stored only on the owner's computer, readable only by the owner. No server, database or third-party storage is involved.
  • Sharing: data is not sold, shared, used for advertising, or used to train AI models.
  • Revoking access: the owner can revoke access at any time at myaccount.google.com/permissions.

Personal Gmail MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
